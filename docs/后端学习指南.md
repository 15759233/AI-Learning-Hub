# 项目后端学习指南（小白版）

## 一、项目后端技术栈
- NestJS（Node.js 的 TypeScript 框架）— 后端骨架
- Prisma（ORM）— 操作 PostgreSQL 数据库
- PostgreSQL — 数据库
- JWT + Cookie — 登录认证
- class-validator — 参数校验

## 二、后端主要模块（server/src/modules）

| 模块 | 作用 |
|---|---|
| auth | 登录/注册/JWT/权限 |
| users | 用户管理 |
| courses | 课程内容 |
| labs | 实训项目（工作台） |
| resources | 资源中心 |
| articles | AI 前沿文章 |
| challenges | 挑战测评 |
| themes | 学习主题 |
| community | 社区（帖子/评论/点赞/关注）|
| feed | 信息流 |
| growth | 成长数据 |
| media / storage | 图片上传、文件存储 |
| questions | 题库（题盒）|
| homepage | 落地页配置 |
| dashboard | 管理端数据看板 |
| signals | 行为埋点（记录用户点击）|
| settings / persistence | 系统设置、启动初始化 |

## 三、后端请求处理流程（核心知识点）

请求 → Controller（接收）→ Service（业务逻辑）→ Prisma（查数据库）→ 返回 JSON

每个模块都这个套路，理解一个就会所有。

## 四、小白必须掌握（基础中的基础）

1. HTTP 基础：GET/POST/PUT/DELETE、状态码（200/400/401/403/404/500）
2. NestJS 三件套：Controller（接口）、Service（逻辑）、Module（组织）
3. Prisma 基本操作：查数据（findMany/findUnique）、写数据（create/update/delete）
4. TypeScript 基础：类型、interface、async/await
5. PostgreSQL 基础：表、字段、外键、SQL 基本查询

## 五、进阶必学（面试/实战重点）

6. 认证与权限：JWT token、Guard（守卫）、RBAC（角色权限）—— 项目里 @UseGuards(AuthGuard) 随处可见
7. DTO 校验：class-validator 校验请求参数（@IsString、@IsOptional）
8. 依赖注入：NestJS 的构造器注入（service 之间互相调用）
9. 事务处理：prisma.$transaction() —— 重要操作要原子性（比如发帖）
10. 分页与游标：列表接口怎么翻页（cursor 分页）

## 六、项目特色点（看懂就加分）

11. 幂等键：idempotency-key 防止重复提交（发帖/评论）
12. 可见性控制：visibility.service 决定谁能看到什么内容（社区）
13. 行为埋点：signals 记录用户行为，分析推荐
14. 文件上传：multer + 存储抽象（本地/S3/MinIO）
15. 错误处理：统一异常过滤器（ApiExceptionFilter）

## 七、建议学习路线（按顺序）

1. 先跑通：看 auth 模块 → 理解登录接口完整流程
2. 再写个简单模块：照着 community 里的模式，自己写一个 CRUD
3. 理解社区模块：Controller → Service → Prisma 的调用链
4. 补基础：TypeScript + SQL 同步学
5. 最后看：权限、事务、幂等这些高级机制
